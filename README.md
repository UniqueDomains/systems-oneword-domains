## 🧱 Field summary

- `domain`, Fully qualified domain name.
- `status`, Current acquisition state for the domain in the public extract.
- `purchase_price`, Visible purchase price when available.
- `renewal_price`, Visible renewal price when available.
- `attractiveness`, Public composite naming band used as a decision-support signal.
- `demand`, Public buyer-pressure band when available.
- `length`, Character count without the TLD.
- `registrar`, Registrar name when known.
- `created_at`, Creation timestamp when known.
- `expires_at`, Expiry timestamp when known.
- `status_verified_at`, When status was last established against the registry. Null means never checked.

See [DATA_DICTIONARY.md](./DATA_DICTIONARY.md) for full definitions and types.

## ⚠️ Methodology and caveats

This selection is made up entirely of one-word .systems domain names — single-token strings with no hyphens or numbers, drawn from a pool of 10,375 listings. Asking prices sit at a median of roughly $25, spanning everything from short, dictionary-style words to longer descriptive compounds such as coffeesyrup.systems and fasttimes.systems. The .systems extension is widely associated with software, IT, and platform-style branding, which makes this list relevant both for buyers evaluating margin and renewal economics and for founders looking for a clean, ownable name for a technical or SaaS-style project. Updated daily, the mix reflects a broad range of word lengths, tones, and niches rather than a single narrow theme.
